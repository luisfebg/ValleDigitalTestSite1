# Valle Digital Test Site 1

Clean development repository for the Valle Digital company website.

## Stack

- Next.js App Router
- TypeScript
- React
- CSS
- Vercel-ready deployment

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Project structure

- `app/` — pages, layouts, metadata, sitemap and robots configuration
- `components/` — reusable site components
- `lib/` — shared site data and utilities
- `public/` — logos, images and icons

This repository is separate from `ValleDigitalTestSite`.
